# Robotics, Made Simple

Robotics, Made Simple helps a parent or grade 6–8 student turn a finalised robotics project idea into an understandable starting parts plan.

This Build Week V1 supports an animal-like robot with hidden wheels. A user enters the project, intended behaviour, buying country, and budget. The app then creates a database-guided parts plan, explains what each part does, and lets the user mark parts they already own or still need.

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown by Vite, usually `http://127.0.0.1:5173/`.

## Current product truth

- The V1 uses the CSV catalogue in `RoboticsPartDB`.
- It does not use live AI, live prices, stock checks, or verified buying links.
- An adult should verify specifications before buying, connecting, or powering hardware.

The controlled Build Week scope is in `IDEA_SCOPE.md`.
